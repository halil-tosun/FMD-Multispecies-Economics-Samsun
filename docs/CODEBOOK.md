## Key Methodological Notes (see manuscript Sections 2.3-2.7 for full detail)

- **Disease-loss model** (Section 2.4): per-farm, per-species loss =
  (baseline milk revenue - observed milk revenue) + (baseline meat
  revenue - observed meat revenue) + additional treatment cost.
  Per-affected-animal loss divides this by the number of affected
  animals. Implemented in `03_species_disease_comparison.py`.
- **Regression model** (Section 2.5): log(per-animal loss) ~ species +
  herd size + illness duration + within-herd prevalence + stratum,
  with farm-level cluster-robust (CR1, small-sample-corrected) standard
  errors, because 81 of 285 farms contribute observations for more than
  one species. Implemented from scratch in NumPy in
  `04_regression_analysis.py` (see module docstring for why no
  off-the-shelf package was used).
- **Moran's I** (Section 2.6): k-nearest-neighbor spatial weights based
  on haversine distance; significance via a 999-iteration permutation
  test; sensitivity assessed across k = 4, 6, 8, 10, 15. Implemented
  from scratch in NumPy in `07_spatial_analysis.py`, for the same
  reason as above.
- **Software** (Section 2.7): Python 3.12, pandas, NumPy, SciPy (for
  Kruskal-Wallis, Mann-Whitney, chi-square, Spearman), Matplotlib for
  all figures.

## Random Seeds and Exact Reproducibility

- `code/_paths.py` sets `TRY_PER_USD = 18.94` (fixed currency conversion;
  see `DATA_DESCRIPTION.md` Section 7).
- `07_spatial_analysis.py` uses `SEED = 42` for the permutation test in
  `morans_i()`. With this seed, Table 6 reproduces exactly.
- No other script in this pipeline uses randomization (the regression,
  descriptive statistics, and non-parametric tests in scripts 01-06 and
  08 are all deterministic given the input data).
